# Next.js Dashboard

A full-stack dashboard application built with Next.js, TypeScript, and Tailwind CSS as part of my practical learning journey with the official Next.js course.

The project explores core concepts involved in building data-driven web applications, including authentication, protected dashboard pages, invoice management, routing, and data fetching.

## Features

- Authentication flow.
- Protected dashboard area.
- Invoice management interface.
- Application routing with Next.js.
- Data fetching and server-side rendering concepts.
- Responsive UI styled with Tailwind CSS.

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Core concepts:** Authentication, routing, data fetching, server-side rendering

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lucianacalisaya/nextjs.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nextjs
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Set up the environment variables required by the project. Consult the environment example file, if available.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open `http://localhost:3000` in your browser.
